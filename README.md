# 身份证照片校正与 1:1 打印工具

一个**单文件、纯本地**的浏览器小工具：把手机拍的身份证照片自动定位四角、透视校正，输出 85.6 × 53.98 mm（ISO/IEC 7810 ID-1）标准尺寸，并排好 A4 1:1 打印页。

> **照片不上传、不存储、不写缓存。** 全部运算在本机浏览器内存中完成，关闭页面即销毁；文件内零处外部链接，可用文本编辑器打开自行核验。

也可以在文件列表点开 `id-card-print-tool.html` → **Raw** → 右键「另存为」。

下载后**双击用 Chrome / Edge 打开**即可，不用安装、不用注册、不用联网。

两点重要说明：

- 微信内置浏览器**无法调起系统打印、也会拦截文件下载**，请务必在电脑浏览器里打开，打印这一步尤其如此。
- `raw.githubusercontent.com` 上的 HTML 由 GitHub 以 `text/plain` + `nosniff` 返回，浏览器只会显示源代码，**不会运行工具**。本仓库未开启 GitHub Pages，也不提供在线版；这是有意为之——分发的是文件，不是网页服务。

## 四步使用

1. 分别上传人像面、国徽面照片（支持点击、拖入、Ctrl+V 粘贴）。
2. 等待自动定位，核对绿框是否贴住卡片外沿；界面显示自动定位置信度。
3. 有偏差时拖动四个圆点，或点「边界智能贴合」；斜拍呈梯形时四角需分别调整。
4. 点「打印此页」或 Ctrl+P。

## 打印设置（六项逐条核对）

① 纸张 A4 纵向　② 边距「无」（不要用「默认」）　③ 缩放「默认 / 实际大小 100%」（不要填自定义百分比、不要选「适应纸张」）　④ 每版打印页数 1　⑤ 关闭「双面打印」与页眉页脚　⑥ 勾选「背景图形」

打印后用尺量卡片宽度，应为 **85.6 mm（允许 ±0.3 mm）**。明显偏小时，检查浏览器缩放、边距，以及打印机驱动里的「适应纸张 / 按纸张缩放」。

左上 20 mm 标尺与页面底部「打印核对」说明仅供屏幕预览，不会打印出来。

- **本仓库不包含、也不接受任何真实身份证照片、校正图或含个人信息的截图。** 请勿在 Issue、Pull Request、Release 附件或提交历史中上传此类内容。Git 历史会永久保留，误传后即使删除当前文件也难以彻底清除。

## 已知局限

自动定位在强反光、卡面被手指或物体遮挡、卡片弯折、背景与卡面反差过低、卡片贴边被裁切或占画面过小时可能失效，此时会给出默认框并提示置信度不足，需手动拖四角。透视校正无法恢复被遮挡的卡面内容。这是纯前端轻量检测的取舍：宁可要求人工确认，也不给一个错误框。
